# Employee Management Web App

This is the final capstone project for Week 02 of the JavaScript curriculum, designed to consolidate all major concepts learned.

## Concepts Mastered in this Project
1. **Arrays & Objects**: Managing state with complex object arrays.
2. **Array Iteration Methods**: 
   - `map()` to transform objects (especially during API integration and editing).
   - `filter()` to delete, search, and filter by department.
   - `reduce()` to dynamically calculate the average salary.
   - `sort()` to order the UI output.
3. **DOM Manipulation**: Utilizing `document.createElement()`, `.append()`, and dynamically mapping JavaScript logic into HTML.
4. **Events**: Binding `click`, `input`, `change`, and intercepting form submissions with `event.preventDefault()`.
5. **Persistence**: Converting objects back and forth to JSON strings using `JSON.stringify()` and `JSON.parse()` to read and write from `localStorage`.
6. **Async/Await & APIs**: Communicating with `JSONPlaceholder` using `fetch()` and transforming external API payloads into local schema structures.
